Crash Reports and Diagnostics

To help maintain and improve the App, we use Sentry, a third-party error monitoring service.

When the App encounters an error or unexpected behavior, diagnostic information may be transmitted to Sentry, including:

  • Error and crash reports
  • Device type and model
  • Operating system version
  • App version
  • Technical diagnostic information relevant to the error
  • Session information related to the error

This information is used solely to identify, investigate, and fix technical issues.

Session Replay

The App uses Sentry Session Replay to help diagnose application errors.

Session Replay records user interactions with the App for debugging purposes. By default, Sentry masks sensitive user content, including text inputs and other potentially sensitive information before data is transmitted.

Session Replay data is used exclusively to investigate and resolve software defects and is not used for advertising, profiling, or marketing purposes.
